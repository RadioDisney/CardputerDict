# 释义选词查询（0.7.1）

普通Cardputer和Cardputer-Adv使用相同操作，支持英汉、汉英以及百科阅读正文。原有SD词库及维基数据包可直接继续使用。

## 操作

1. 打开词条释义或百科文章，按 **Ctrl+F** 进入选词模式，当前页正文出现一像素宽的竖线光标，每500ms闪烁一次；移动后立即显示光标。
2. 直接按 **← / →** 移动一个完整字符；**↑ / ↓** 移动到前后行，并尽量保持视觉列位置。
3. 按住 **Ctrl** 再按方向键，扩展或缩小选择范围。可以向前或向后选择，范围会高亮；方向键到达页边缘可跨到相邻阅读页。
4. 按 **Enter** 查询选中文字，状态栏立即显示“查询中…”，再读取所选文字并查词；成功后打开新词条。原Ctrl+Enter也可继续使用。
5. **Ctrl+F、反引号或Backspace** 退出选词并留在原阅读页；选词退出后再次Backspace仍按原操作返回列表。

例如：在apple英汉释义里选择“苹果”，Enter可进入汉英“苹果”；再选择其中的Apple，可回到英汉apple。百科里选择已有标题可直接打开相应文章。

方向键与Ctrl+方向键均支持长按：按住450ms后开始，每125ms移动一次；松开即停止。Fn+方向键输入标点时不连发。切换词条、开启/关闭选词和查询时停止原有连发，避免误操作新页面。

## 查询规则

- 优先精确查询当前词库；当前百科有对应标题时留在百科。
- 当前词库未命中时，根据所选文字的中英文，尝试汉英或英汉词典。
- 不自动把相近前缀当成命中。未找到时保留当前阅读页、光标和选区，便于调整。
- 没有选择范围时提示先用Ctrl+方向键选词；范围过长时提示缩小，不会把整篇文章读入内存。
- 换行、Tab等空白在查询时整理为空格；自动折行不会在词中插入额外字符。中文、UTF-8四字节字符及组合音标按完整字符边界处理。

## 阅读与兼容

选词模式中的方向键用于移动光标；退出后恢复直接方向键翻页。选词到文章首尾会停住，不循环跳到另一端；普通阅读的首尾循环保持原样。Tab仍按SD已安装词库切换，Ctrl+Space在查询输入页切换拼音/直接输入，Fn+方向键仍为标点。

本次版本只更新应用，不改写SD数据结构。光标仅保留当前页的字符位置，百科继续按需分页读取，不缓存整篇文章。当前查询最多使用一个词条长度的文本，过大的选区只保留位置，不会分配同等大小的缓冲。
