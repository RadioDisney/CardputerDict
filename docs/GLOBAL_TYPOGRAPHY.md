# 全局半角 / 全角字距：0.2.4

日期：2026-11-11（Asia/Shanghai）。

所有屏幕文本共用 ui::printText / ui::textWidth：半角字符后增加 1 像素，全角及宽字符后增加 2 像素；末字符不额外添加尾部空隙。使用 Unicode East Asian Width W/F 判断宽字符，半角片假名、普通拉丁字母、数字、音标和 ASCII 标点采用 1 像素。组合附加符、变体选择符及格式控制符不额外插入间距。

范围包括标题、词头、查询框、匹配列表、释义、候选、帮助、状态栏、索引 / USB 传输进度和内存错误提示。候选保持单行，宽度计算、换行、尾部省略和分页均使用相同规则。

## 验证

- 主机测试通过：半角 / 全角标点、全角拉丁字母、半角片假名、CJK、音标、组合符、UTF-8 解码、绘制位置与测量一致性、多行以及候选分页。AddressSanitizer / UndefinedBehaviorSanitizer 无错误。
- 既有词库核心、单行候选和 Python 转换测试通过。
- 编译、USB 烧录及 Flash 摘要校验通过；设备返回 0.2.4、240×135、rotation=0、spacing half=1 full=2。
- 实机：单行候选保持 8 个单字 / 5 个双字词；第 8 项、下一页首项、第 5 个词及隐藏编号保护均通过。
- 已抓取并目视检查英汉释义、汉英释义、中文查询框、单字 / 词组候选及状态栏，未见右侧裁切或字符重叠。
- 实机像素对比：14 字符英文主标题右端增加 13 像素；5 字符英文词头增加 4 像素；中文双字词头增加 2 像素。正文半角音标相较旧统一 2 像素字距减少 5 像素，符合半角间距改为 1 像素。

原生截图、测试日志和像素边界记录见 docs/validation-v024/。
