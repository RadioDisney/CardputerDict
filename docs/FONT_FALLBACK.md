# 0.5.1 繁体字回退补字

2026-11-16，主工程：/Users/huxunxun/WorkSpace/CardputerDict。

“苹果”释义的原文 CL:個|个[ge4],顆|颗[ke1] 包含繁体“個”(U+500B)、“顆”(U+9846)。efontCN_12/14/16 均缺少这两个字及“蘋”，efontTW 对应字号包含这些字。

新增 cjk_font.h：先使用CN字形，缺字时回退TW；正文保留IPA优先级。12/14/16px的标题、释义、列表、候选和其他文字统一使用回退字体。保持原简体字形、字号、基线、半角1px/全角2px字距和释义4px留白。

- PlatformIO构建成功。RAM66180字节（原66108，增加72字节）；程序3536413字节，占6MiB应用分区56.2%。额外繁体字库存放于Flash，约增加1.46MB。
- 8个原生测试程序（ASan/UBSan）、14个Python用例全部通过。新增测试直接检查锁定版本M5GFX的CN/TW字库数据，验证缺字回退覆盖及三种字号的行高/全角宽度。
- Adv（70:af:09:df:1d:c0）和普通版（c0:4e:30:13:12:70）都已仅刷写应用分区0x10000，写入摘要校验通过；升级前后WiFi配置标志和音量一致，SD数据保留。
- 两台“苹果”第二页均由两个方框变为“個”“顆”，每台仅这两个字形区域改变141个像素；其余屏幕像素不变。
- 两台TESLA完整截图与0.5.0逐像素完全相同，IPA/Cyrillic音标及布局保持一致。
- “蘋果”的查询标题和词条列表正常；英汉/汉英、简繁查询、整词拼音、候选分页/选择和紧凑布局实机测试全部通过。
