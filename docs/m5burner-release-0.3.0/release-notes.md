## 0.3.0：SD 索引持久化与快速启动

- 将校验后的稀疏索引序列化为 SD 上的 .cidx 文件；英汉、汉英和拼音分别缓存。
- 缓存包含版本、源文件信息、内容抽样指纹和 CRC32；检查失败自动重建，写入采用临时文件与回读校验。
- 实机英汉索引加载由约 60.7 秒降至 0.39 秒；连续三次软件重启约 1.32 秒到可用界面。首次安装词库仍需完整扫描一次。
- 保留全局半角 1 像素 / 全角 2 像素字距、释义 4 像素行间留白、备选词条滚动和右上角 [Tab] 提示。
- 修复 TESLA 音标中的 ә 缺字，扩展音标后备字库。

源码版本：ceefab088b8fccb9f9c390f8e75d79cc714d13f1。

固件为普通 Cardputer 的 ESP32-S3 8 MB Flash 完整合并 .bin，烧录地址 0x0；完整词库需另外复制到 microSD。
