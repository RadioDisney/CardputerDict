# 退格 125ms 与同键快速连按：0.4.2

2026-11-12（Asia/Shanghai）。

## 行为

退格长按首次等待仍为 450ms，重复间隔由 65ms 改为 125ms。释放即停，Fn+退格保持单次清空。长按期间只刷新输入文字，松手后再查询 SD 匹配词条，避免每次删除之间的 SD 查找拖慢节奏。

键盘不再依附主循环的界面刷新：独立 Core 0 任务按 1ms RTOS tick 扫描矩阵，2ms 稳定状态去抖，最多 96 项按下/释放事件排队。主线程只消费事件和处理界面，扫描任务唯一拥有可变键盘 reader；修饰键随事件快照传递。

朗读忙碌期间捕获的输入标记为 audio 上下文，结束后不会当普通文字补输。下载取消键读取线程安全的稳定状态，不再在另一线程操作键盘 reader。

## 验证

- ASan/UBSan 主机时序测试：450ms 首次延迟、125ms 重复、释放、修饰键抑制、慢帧不突发及计时回绕。
- 扫描测试：2ms 去抖、抖动过滤、4ms 松手重复键、阻塞 UI 后保留全部按下/释放、组合键和计时回绕。既有音频、索引缓存、字距及候选测试通过。
- 编译与 USB 烧录成功，Flash 摘要校验通过。
- 设备诊断向同一真实扫描/去抖/事件队列注入原始轨迹：按下 8ms、松手 4ms，hello、letterll、bookkeeper、mississippi、eeeeeeee 均完整进入查询框。此为时序轨迹注入，不是机械开关手感测量。
- 实机注入退格按住 1200ms：共删除 7 次，释放后等待 300ms 无额外删除；单次退格仍只删一个字符。
- 实机扫描诊断：tick=1ms、debounce=2ms、dropped=0；测试阶段最大扫描间隔约 1.231ms，刷新与朗读后仍无队列丢失。
- 朗读 apple 完成 56,208 PCM 帧、峰值 24,918，正常回到完整 770,611 词库。WiFi 设置保留，未主动联网。

物理键盘可直接试打 ll / ee 体验；按下/释放不再要求跨过一次屏幕刷新周期。记录见 docs/validation-v042/。
